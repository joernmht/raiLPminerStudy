## 4.1 The composition model for rolling stock rescheduling

The composition model for the Rolling Stock Rescheduling Problem (RSRP) as described by Nielsen (2011) allocates a composition of rolling stock units to every trip in a set of trips in the timetable $T$. Each trip $t \in T$ has an associated departure time ${\tau}_{\text{d}} ( t )$, arrival time ${\tau}_{\text{a}} ( t )$, departure station ${s}_{\text{d}} ( t )$ and arrival station ${s}_{\text{a}} ( t )$. The successor trip of trip $t$ is denoted by $v ( t )$. The set ${T}_{1}$ denotes the set of trips which have no successor trip.

Let $C$ be the set of all possible rolling stock compositions for each trip. Let ${C}_{t}$ denote the set of compositions that are allowed for trip $t$. A composition is allowed if the correct type of rolling stock units is used, if enough seating capacity is available to provide a certain passenger service level and if the length of the composition does not exceed a certain upper bound. This set also contains the empty composition that is employed if a trip is canceled, which is denoted by $c = 0$. The set ${\Gamma}_{t}$ denotes the possible transitions for trip $t$, which consist of pairs of compositions $( c , {c}^{ ' } )$ such that $c \in {C}_{t}$ and ${c}^{ ' } \in {C}_{v ( t ) }$, and such that the composition change from $c$ to ${c}^{ ' }$ is allowed after trip $t$.

The set of stations at which rolling stock units are available and can be (un)coupled is denoted by $S$. The time it takes for an uncoupled rolling stock unit to be available for coupling at station $s$ is denoted by $\rho ( s )$. All rolling stock unit subtypes $m$ are contained in the set $M$. Furthermore, ${n}_{m}$ denotes the number of type $m$ rolling stock units that are available on the railway network. Moreover, ${\alpha}_{c , {c}^{ ' }}^{m}$ and ${\beta}_{c , {c}^{ ' }}^{m}$ denote the number of uncoupled and coupled units, respectively, of type $m$ during transition $( c , {c}^{ ' } )$. We also denote by ${\mathrm{carr}}_{c}$ the number of carriages in composition $c$ and by ${\mathrm{seat}}_{c}^{t}$ the expected number of seat-shortages for trip $t$ when composition $c$ is used. The length of trip $t$ in kilometers is represented by ${l}_{t}$ and the duration of trip $t$ in hours is represented by ${h}_{t}$.

We denote by ${p}_{0}^{t}$ the original composition of trip $t$ in the original schedule, by $o{c}^{t}$ and $o{u}^{t}$ the original number of coupled units right before trip $t$ and the original number of uncoupled units right after trip $t$, respectively, and by ${i}_{m , 0}^{s}$ and ${i}_{m , \text{end}}^{s}$ respectively the original initial and ending inventory of rolling stock unit type $m$ at station $s$. Additionally, ${\tau}_{\text{disr}}$ denotes the starting time of the disruption.

We define the binary variable ${x}_{c}^{t}$ which takes on the value 1 if composition $c \in C$ is chosen for trip $t \in T$, and 0 otherwise. Additionally, the binary variable ${z}_{c , {c}^{ ' }}^{t}$ has value 1 if trip $t \in T$ has composition $c \in C$ and trip $v ( t )$ has composition ${c}^{ ' } \in C$, and 0 otherwise. The variables ${c}_{m}^{t}$ and ${u}_{m}^{t}$ denote the number of rolling stock units $m$ that are coupled to the composition right before trip $t$ and uncoupled from the composition right after trip $t$, respectively. Additionally, the variable ${I}_{m}^{t}$ expresses the number of rolling stock units of type $m$ that are in inventory at station ${s}_{\text{d}} ( t )$ right after the departure of trip $t$. The variables ${I}_{m , 0}^{s}$ and ${I}_{m , \text{end}}^{s}$ denote the initial inventory and the inventory at the end of the day of type $m$ at station $s$, respectively.

The binary variable ${p}_{\text{diff}}^{t}$ takes on the value 1 if trip $t$ is executed with a different composition than the originally planned composition ${p}_{0}^{t}$ and 0 otherwise. The variables $n{c}_{t}$ and $n{u}_{t}$ represent the number of additional coupled units right before trip $t$ and the number of additional uncoupled units right after trip $t$, respectively. The variable ${I}_{m , \text{off}}^{s}$ denotes the off-balance in the ending inventory of rolling stock unit type $m$ of station $s$. Furthermore, we define seven weights ${w}_{1}$–${w}_{7}$ for the different factors of the objective function. A Mixed Integer Program (MIP) formulation is then as follows: 

$$ min \;{ \sum }_{t \in T}{ \sum }_{c \in {C}_{t}}{w}_{1}\cdotcar{r}_{c}\cdot{l}_{t}\cdot{x}_{c}^{t} + { \sum }_{t \in T}{ \sum }_{c \in {C}_{t}}{w}_{2}\cdotsea{t}_{c}^{t}\cdot{h}_{t}\cdot{x}_{c}^{t} + { \sum }_{t \in T}{w}_{3}\cdot{x}_{0}^{t} + \;{ \sum }_{s \in S}{ \sum }_{m \in M}{w}_{4}\cdot{I}_{m , \text{off}}^{s} + { \sum }_{t \in T}{w}_{5}\cdotn{c}_{t} + { \sum }_{t \in T}{w}_{6}\cdotn{u}_{t} + { \sum }_{t \in T}{w}_{7}\cdot{p}_{\text{diff}}^{t} \tag{1} $$

$$ \text{s.t.}\;{ \sum }_{c \in {C}_{t}}{x}_{c}^{t} = 1\; \forall t \in T \tag{2} $$

$$ {x}_{c}^{t} = { \sum }_{{c}^{ ' } \in {C}_{v ( t ) } : ( c , {c}^{ ' } ) \in {\Gamma}_{t}}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;c \in {C}_{t} \tag{3} $$

$$ {x}_{{c}^{ ' }}^{v ( t ) } = { \sum }_{c \in {C}_{t} : ( c , {c}^{ ' } ) \in {\Gamma}_{t}}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;{c}^{ ' } \in {C}_{v ( t ) } \tag{4} $$

$$ {c}_{m}^{v ( t ) } = { \sum }_{(c , {c}^{ ' }) \in {\Gamma}_{t}}{\beta}_{c , {c}^{ ' }}^{m}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;m \in M \tag{5} $$

$$ {u}_{m}^{t} = { \sum }_{(c , {c}^{ ' }) \in {\Gamma}_{t}}{\alpha}_{c , {c}^{ ' }}^{m}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;m \in M \tag{6} $$

$$ {I}_{m}^{t} = {I}_{m , 0}^{{s}_{d} ( t ) } - { \sum }_{\frac{{t}^{ ' } \in T : {s}_{\text{d}} ( {t}^{ ' } ) = {s}_{\text{d}} ( t ) , }{{\tau}_{\text{d}} ( {t}^{ ' } ) \le {\tau}_{\text{d}} ( t ) }}{c}_{m}^{{t}^{ ' }} + { \sum }_{\frac{{t}^{ ' } \in T : {s}_{\text{a}} ( {t}^{ ' } ) = {s}_{\text{d}} ( t ) , }{{\tau}_{\text{a}} ( {t}^{ ' } ) \le {\tau}_{\text{d}} ( t ) - \rho ( {s}_{\text{d}} ( t ) ) }}{u}_{m}^{{t}^{ ' }}\; \forall t \in T , \;m \in M \tag{7} $$

$$ {I}_{m , \text{end}}^{s} = {I}_{m , 0}^{s} - { \sum }_{t \in T : {s}_{\text{d}} ( t ) = s}{c}_{m}^{t} + { \sum }_{t \in T : {s}_{\text{a}} ( t ) = s}{u}_{m}^{t}\; \forall s \in S , \;m \in M \tag{8} $$

$$ {p}_{\text{diff}}^{t} \ge { \sum }_{c \in C : c \neq {p}_{0}^{t}}{x}_{c}^{t}\; \forall t \in T \tag{9} $$

$$ n{c}_{t} \ge { \sum }_{m \in M}{c}_{m}^{t} - o{c}_{t} \forall t \in T \tag{10} $$

$$ n{u}_{t} \ge { \sum }_{m \in M}{u}_{m}^{t} - o{u}_{t} \forall t \in T \tag{11} $$

$$ {I}_{m , \text{off}}^{s} \ge {I}_{m , \text{end}}^{s} - {i}_{m , \text{end}}^{s} \forall s \in S , \;m \in M \tag{12} $$

$$ {I}_{m , \text{off}}^{s} \ge {i}_{m , \text{end}}^{s} - {I}_{m , \text{end}}^{s} \forall s \in S , \;m \in M \tag{13} $$

$$ {I}_{m , 0}^{s} = {i}_{m , 0}^{s} \forall s \in S , \;m \in M \tag{14} $$

$$ {x}_{{p}_{0}^{t}}^{t} = 1 \forall t \in T : {\tau}_{\text{d}} ( t ) \le {\tau}_{\text{disr}} \tag{15} $$

$$ {c}_{m}^{t} , {u}_{m}^{t} , {I}_{m}^{t} \in {R}^{ + }\; \forall t \in T , \;m \in M \tag{16} $$

$$ {I}_{m , 0}^{s} , {I}_{m , \text{end}}^{s} , {I}_{m , \text{off}}^{s} \in {R}^{ + }\; \forall s \in S , \;m \in M \tag{17} $$

$$ n{c}_{t} , n{u}_{t} \in {R}^{ + } \forall t \in T \tag{18} $$

$$ {x}_{c}^{t} \in \{ 0 , 1 \} \; \forall t \in T , \;c \in {C}_{t} \tag{19} $$

$$ {z}_{c , {c}^{ ' }}^{t} \in \{ 0 , 1 \} \; \forall t \in T , \; ( c , {c}^{ ' } ) \in {\Gamma}_{t} \tag{20} $$

 
 

$$ {p}_{\text{diff}}^{t} \in \{ 0 , 1 \} \; \forall t \in T \tag{21} $$

The objective function (1) aims to minimize the number of driven carriage kilometers, the number of seat-shortage hours, the number of cancellations, off-balances in the ending inventories, the number of additional (un)coupled units and the number of different compositions compared to the initial rolling stock schedule. Constraints (2) ensure that exactly one rolling stock composition is chosen for each trip $t$. Constraints (3) link the binary variables by guaranteeing that a composition $c$ is chosen for trip $t$ if and only if an allowed composition change is chosen such that composition ${c}^{ ' }$ is used for the successor trip $v ( t )$ of trip $t$. Constraints (4) take on a similar role for the predecessor trips. Constraints (5) and (6) model the number of coupled and uncoupled rolling stock units for each composition change, respectively. Constraints (7) describe the inventory of rolling stock units after each trip. This is done by taking the initial inventory at the departure station of trip $t$, subtracting the number of rolling stock units that have been coupled to departing trains and adding the number of rolling stock units that have been uncoupled from arriving trains up until the departure of trip $t$. Constraints (8) model the ending inventories of each rolling stock unit type at each station, by adding all coupled units to and subtracting all uncoupled units from the initial inventory of the considered station. Constraints (9) ensure that the binary variable ${p}_{\text{diff}}^{t}$ takes on the value 1 if a different composition is chosen for trip $t$. Constraints (10) and (11) model the additional coupled and uncoupled units, respectively. Since the variables $n{c}_{t}$ and $n{u}_{t}$ are non-negative, only additional shunting movements are taken into account. Constraints (12) and (13) ensure that the variables ${I}_{m , \text{off}}^{s}$ are equal to the absolute value of the off-balance between the ending inventory of the original plan and the ending inventory of the adjusted plan. Constraints (14) specify that the initial inventories are equal to the planned initial inventories. Constraints (15) fix the chosen compositions for all trips that take place before the disruption occurs. Constraints (16)–(21) specify the domains of the decision variables.

## 4.2 The infrastructure model for railway availability

The purpose of the formulation that is covered in this section is to ensure that the performed shunting movements cause no headway or infrastructure availability conflicts with each other and with other planned trains. We utilize constraints similar to those in the Train Timetable Adjustment Problem (TTAP) as described by Van Aken et al. (2017), which aims at finding an alternative timetable that minimizes the deviation from the original timetable in terms of the incurred delays and cancellations of train services. This problem models all trips in the timetable as train events and ensures that the minimum headway is kept between all trains and that the station and track capacities are satisfied.

The formulation that we introduce in this section checks the feasibility of all shunting movements that take place at one station $s \in S$. We therefore only model the infrastructure of the station at which the shunting movements take place and enforce the headway constraints for each train trip and shunting movement that arrives at or departs from $s$ during the disruption. We work with an initial timetable for which all headway constraints are satisfied and therefore do not model the headway constraints for the rest of the railway network. Furthermore, since we allow for delays of through passing trains of at most a few minutes, we assume that any delays that are incurred at the considered station in this step are resolved by the buffers that are present in the timetable, thereby maintaining the feasibility of the initial timetable.

The set $N = {N}^{T} \cup {N}^{S}$ contains all planned passenger trains ${N}^{T}$ that pass through $s$ and all shunting movements ${N}^{S}$ that take place at $s$, with the latter consisting of trips from a specific track of $s$ to a shunting track at (one of) its shunting yard(s), or vice versa. We define the set of infrastructure points $P$ which contains all tracks and crossings at $s$. Station tracks and shunting tracks are often connected through crossings, on which the minimum headway must be respected. The headway constraints are in place for all train services and shunting movements that make use of the same track and/or crossing.

We create an event–activity network which is characterized by a directed graph $G = ( E , A )$, where $E$ represents the set of vertices, or events, and $A$ represents the set of arcs, or activities, which connect the events with each other. The set $E$ contains all arrival events and departure events that take place at the considered station $s$. We denote by ${E}_{n}$ the events belonging to train $n \in N$. The original timetable assigns a time ${\pi}_{i}$ to each event $i \in E$. Note that the original timetable only contains arrivals at and departures from a specific platform track at the station, whilst we are interested in all other pieces of track and crossings that a passenger train uses to enter and leave the station. For this purpose, we introduce the parameter $r$ which represents the time it takes in seconds to travel between infrastructure points. The event set $E$ is then extended to also contain arrival and departure events at every infrastructure point for each passenger train, with $r$ seconds between each departure and arrival event and 0 s between each arrival and departure event. Passenger trains that are planned to wait at a platform track maintain their waiting time between this arrival and departure event. We model shunting movements in the same way as the passenger trains.

The set $A$ contains the activities that connect the arrival and departure events. We define four types of activities that comprise $A$. Driving activities ${A}_{\text{drive}}^{n}$ model the driving of train $n \in N$ between two infrastructure points, i.e., driving activities connect the departure event from one point to the arrival event at the next point. Since trains do not stop at infrastructure points, we model the arrival event and departure event of a train $n \in N$ at an infrastructure point $p \in P$ to take place at the same time. Dwelling activities ${A}_{\text{dwell}}^{n}$ connect the arrival event of a passenger train $n \in N$ at a platform to the subsequent departure event. We define headway activities ${A}_{\text{headway}}^{p}$ which link the arrival and departure events of trains and/or shunting movements that make use of the same infrastructure point $p \in P$. Furthermore, the set ${A}_{\text{shunt}}$ denotes the shunting activities which for instance link the arrival event of a passenger train at a station to an uncouple movement, i.e., the departure event of a rolling stock unit which has been uncoupled from the incoming train and which is transported to the shunting yard. Couple movements are linked to departing compositions in a similar way.

Each activity is bounded by a minimum and maximum amount of time that the activity can take. In particular, we define the activity-specific lower bounds ${l}_{i , j}$ and upper bounds ${u}_{i , j}$ for each activity $( i , j ) \in {A}_{\text{drive}} \cup {A}_{\text{dwell}} \cup {A}_{\text{shunt}}$. For shunting movements, we assume that there is a minimum and maximum time that must and may be present between the arrival of a rolling composition at its track and the uncoupling movements that involve rolling stock unit(s) belonging to the considered composition, respectively. For couple movements, the coupled unit needs to be retrieved from the shunting yard and must be present at its desired track at least ${l}_{i , j}$ and at most ${u}_{i , j}$ before the departure of the train it is coupled to. Initially, we plan for an uncoupling movement to take place ${l}_{i , j}$ minutes after the arrival of the incoming composition and for a to be coupled unit to arrive at the platform track ${l}_{i , j}$ minutes before the departure of the new composition. Furthermore, we define the minimum headway ${h}_{i , j}$ that must be present between each activity $( i , j ) \in {A}_{\text{headway}}^{p}$ for all $p \in P$.

We define the variable ${v}_{i}$ which represents the time of event $i \in E$. To keep track of the order of events, a binary variable ${q}_{i , j}$ is introduced for every activity $( i , j ) \in A$, which is equal to 0 if event $i$ takes place chronologically before event $j$ and 1 otherwise. Furthermore, the binary variable ${X}_{n}$ is equal to 1 if shunting movement $n \in {N}^{S}$ is canceled and 0 otherwise. We also define the variable ${d}_{j}$, which measures the deviation in the event time ${v}_{j}$ from the original time in minutes. The parameter ${d}_{ max }^{ + }$ indicates the maximum allowed deviation and the variable ${a}_{j}$ represents the absolute value of the deviation of event $j$ compared to the original timetable. The parameters ${w}_{j}^{\text{deviation}}$ and ${w}_{n}^{\text{cancel}}$ represent the weights of the deviation of event $j$ and the cancellation of train $n$, respectively. We introduce the time horizon as $[ 0 , D ]$, with 0 indicating the start of the day and $D$ indicating the end of the day in minutes. The formulation is then as follows: 

$$ \mathrm{min}\;{ \sum }_{j \in E}{w}_{j}^{\text{deviation}}\cdot{a}_{j} + { \sum }_{n \in {N}^{S}}{w}_{n}^{\text{cancel}}\cdot{X}_{n}\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \tag{22} $$

$$ \mathrm{s.t.}\;\;0 \le {v}_{j} \le D ( 1 - {X}_{n} ) \;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in N , \; \forall j \in {E}_{n} \tag{23} $$

$$ {l}_{i , j}(1 - {X}_{n}) \le {v}_{j} - {v}_{i} \le {u}_{i , j}(1 - {X}_{n})\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in N , \; \forall ( i , j ) \in {A}_{\text{drive}}^{n} \cup {A}_{\text{dwell}}^{n} \tag{24} $$

$$ {l}_{i , j}(1 - {X}_{m} - {X}_{n}) \le {v}_{j} - {v}_{i} + {q}_{i , j}D \le {u}_{i , j}(1 - {X}_{m} - {X}_{n}) + D({X}_{m} + {X}_{n})\;\;\;\;\;\;\; $$

$$ \;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall ( i , j ) \in {A}_{\text{shunt}} , \;i \in {E}_{m} , j \in {E}_{n} , \;m , n \in N \tag{25} $$

$$ {h}_{i , j}(1 - {X}_{m} - {X}_{n}) \le {v}_{j} - {v}_{i} + {q}_{i , j}D \le (D - {h}_{i , j})(1 - {X}_{m} - {X}_{n}) + D({X}_{m} + {X}_{n})\;\;\;\; $$

$$ \;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall p \in P , \; \forall ( i , j ) \in {A}_{\text{headway}}^{p} , \;i \in {E}_{m} , j \in {E}_{n} , \;m , n \in N \tag{26} $$

$$ {d}_{j} = {v}_{j} - {\pi}_{j}(1 - {X}_{n})\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in N , \; \forall j \in {E}_{n} \tag{27} $$

$$ 0 \le {d}_{j} \le {d}_{ max }^{ + }\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in {N}^{T} , \; \forall j \in {E}_{n} \tag{28} $$

$$ - {d}_{ max }^{ + } \le {d}_{j} \le {d}_{ max }^{ + }\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in {N}^{S} , \; \forall j \in {E}_{n} \tag{29} $$

$$ {a}_{j} \ge {d}_{j}\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall j \in E \tag{30} $$

$$ {a}_{j} \ge - {d}_{j}\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall j \in E \tag{31} $$

$$ {X}_{n} = 0\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in {N}^{T} \tag{32} $$

$$ {v}_{j} , {a}_{j} \in {R}^{ + }\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall j \in E \tag{33} $$

$$ {d}_{j} \in R\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall j \in E \tag{34} $$

$$ {q}_{i , j} \in \{ 0 , 1 \} \;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall ( i , j ) \in A \tag{35} $$

$$ {X}_{n} \in \{ 0 , 1 \} \;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\; \forall n \in N \tag{36} $$

The objective function (22) minimizes a weighted sum of the incurred deviations from the original timetable and the cancellations of shunting movements. Constraints (23) limit the time of every event $j$ to range between 0 and $D$. If the shunting movement $n$, which event $j$ is part of, is canceled, ${v}_{j}$ is set to 0. Constraints (24) set the time of every driving and dwelling activity to range between the activity-specific predefined lower bound and upper bound. Constraints (25) ensure that the minimum (un)couple time is present between the arrival of a composition and the uncouple movements of its unit(s) and between the arrival of its coupled unit(s) and the departure of the new composition. In the former case, event $j$ of shunting movement $n$ corresponds to the uncouple movement and event $i$ of passenger train $m$ corresponds to the arrival of the old composition. If this uncouple movement is canceled, the variable ${q}_{ij}$ is required to make the middle term non-negative. In the latter case, event $i$ of shunting movement $m$ corresponds to the couple movement and event $j$ of passenger train $n$ corresponds to the departure of the new composition. To model the headway and crossing requirements, Constraints (26) create a safety distance between shunting movements and/or passenger trains $m , n \in N$ for all headway activities on all infrastructure points $p \in P$. If event $j$ takes place before event $i$, ${q}_{ij}$ takes on the value 1. The deviations of the event times from the original timetable are modeled by Constraints (27) and limited by Constraints (28) and (29). Constraints (30) and (31) model the absolute deviations of the event times and Constraints (32) prevent the cancellations of passenger trains. Constraints (33)–(36) indicate the domains of the decision variables.
