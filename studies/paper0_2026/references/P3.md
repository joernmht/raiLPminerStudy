## 4.1 The composition model for rolling stock rescheduling

The composition model for the Rolling Stock Rescheduling Problem (RSRP) as described by Nielsen (2011) allocates a composition of rolling stock units to every trip in a set of trips in the timetable $T$. Each trip $t \in T$ has an associated departure time ${\tau}_{\text{d}} ( t )$, arrival time ${\tau}_{\text{a}} ( t )$, departure station ${s}_{\text{d}} ( t )$ and arrival station ${s}_{\text{a}} ( t )$. The successor trip of trip $t$ is denoted by $v ( t )$. The set ${T}_{1}$ denotes the set of trips which have no successor trip.

Let $C$ be the set of all possible rolling stock compositions for each trip. Let ${C}_{t}$ denote the set of compositions that are allowed for trip $t$. A composition is allowed if the correct type of rolling stock units is used, if enough seating capacity is available to provide a certain passenger service level and if the length of the composition does not exceed a certain upper bound. This set also contains the empty composition that is employed if a trip is canceled, which is denoted by $c = 0$. The set ${\Gamma}_{t}$ denotes the possible transitions for trip $t$, which consist of pairs of compositions $( c , {c}^{ ' } )$ such that $c \in {C}_{t}$ and ${c}^{ ' } \in {C}_{v ( t ) }$, and such that the composition change from $c$ to ${c}^{ ' }$ is allowed after trip $t$.

The set of stations at which rolling stock units are available and can be (un)coupled is denoted by $S$. The time it takes for an uncoupled rolling stock unit to be available for coupling at station $s$ is denoted by $\rho ( s )$. All rolling stock unit subtypes $m$ are contained in the set $M$. Furthermore, ${n}_{m}$ denotes the number of type $m$ rolling stock units that are available on the railway network. Moreover, ${\alpha}_{c , {c}^{ ' }}^{m}$ and ${\beta}_{c , {c}^{ ' }}^{m}$ denote the number of uncoupled and coupled units, respectively, of type $m$ during transition $( c , {c}^{ ' } )$. We also denote by ${\mathrm{carr}}_{c}$ the number of carriages in composition $c$ and by ${\mathrm{seat}}_{c}^{t}$ the expected number of seat-shortages for trip $t$ when composition $c$ is used. The length of trip $t$ in kilometers is represented by ${l}_{t}$ and the duration of trip $t$ in hours is represented by ${h}_{t}$.

We denote by ${p}_{0}^{t}$ the original composition of trip $t$ in the original schedule, by $o{c}^{t}$ and $o{u}^{t}$ the original number of coupled units right before trip $t$ and the original number of uncoupled units right after trip $t$, respectively, and by ${i}_{m , 0}^{s}$ and ${i}_{m , \text{end}}^{s}$ respectively the original initial and ending inventory of rolling stock unit type $m$ at station $s$. Additionally, ${\tau}_{\text{disr}}$ denotes the starting time of the disruption.

We define the binary variable ${x}_{c}^{t}$ which takes on the value 1 if composition $c \in C$ is chosen for trip $t \in T$, and 0 otherwise. Additionally, the binary variable ${z}_{c , {c}^{ ' }}^{t}$ has value 1 if trip $t \in T$ has composition $c \in C$ and trip $v ( t )$ has composition ${c}^{ ' } \in C$, and 0 otherwise. The variables ${c}_{m}^{t}$ and ${u}_{m}^{t}$ denote the number of rolling stock units $m$ that are coupled to the composition right before trip $t$ and uncoupled from the composition right after trip $t$, respectively. Additionally, the variable ${I}_{m}^{t}$ expresses the number of rolling stock units of type $m$ that are in inventory at station ${s}_{\text{d}} ( t )$ right after the departure of trip $t$. The variables ${I}_{m , 0}^{s}$ and ${I}_{m , \text{end}}^{s}$ denote the initial inventory and the inventory at the end of the day of type $m$ at station $s$, respectively.

The binary variable ${p}_{\text{diff}}^{t}$ takes on the value 1 if trip $t$ is executed with a different composition than the originally planned composition ${p}_{0}^{t}$ and 0 otherwise. The variables $n{c}_{t}$ and $n{u}_{t}$ represent the number of additional coupled units right before trip $t$ and the number of additional uncoupled units right after trip $t$, respectively. The variable ${I}_{m , \text{off}}^{s}$ denotes the off-balance in the ending inventory of rolling stock unit type $m$ of station $s$. Furthermore, we define seven weights ${w}_{1}$–${w}_{7}$ for the different factors of the objective function. A Mixed Integer Program (MIP) formulation is then as follows: 

$$ min \;{ \sum }_{t \in T}{ \sum }_{c \in {C}_{t}}{w}_{1}\cdotcar{r}_{c}\cdot{l}_{t}\cdot{x}_{c}^{t} + { \sum }_{t \in T}{ \sum }_{c \in {C}_{t}}{w}_{2}\cdotsea{t}_{c}^{t}\cdot{h}_{t}\cdot{x}_{c}^{t} + { \sum }_{t \in T}{w}_{3}\cdot{x}_{0}^{t} + \;{ \sum }_{s \in S}{ \sum }_{m \in M}{w}_{4}\cdot{I}_{m , \text{off}}^{s} + { \sum }_{t \in T}{w}_{5}\cdotn{c}_{t} + { \sum }_{t \in T}{w}_{6}\cdotn{u}_{t} + { \sum }_{t \in T}{w}_{7}\cdot{p}_{\text{diff}}^{t} \tag{1} $$

$$ \text{s.t.}\;{ \sum }_{c \in {C}_{t}}{x}_{c}^{t} = 1\; \forall t \in T \tag{2} $$

$$ {x}_{c}^{t} = { \sum }_{{c}^{ ' } \in {C}_{v ( t ) } : ( c , {c}^{ ' } ) \in {\Gamma}_{t}}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;c \in {C}_{t} \tag{3} $$

$$ {x}_{{c}^{ ' }}^{v ( t ) } = { \sum }_{c \in {C}_{t} : ( c , {c}^{ ' } ) \in {\Gamma}_{t}}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;{c}^{ ' } \in {C}_{v ( t ) } \tag{4} $$

$$ {c}_{m}^{v ( t ) } = { \sum }_{(c , {c}^{ ' }) \in {\Gamma}_{t}}{\beta}_{c , {c}^{ ' }}^{m}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;m \in M \tag{5} $$

$$ {u}_{m}^{t} = { \sum }_{(c , {c}^{ ' }) \in {\Gamma}_{t}}{\alpha}_{c , {c}^{ ' }}^{m}{z}_{c , {c}^{ ' }}^{t}\; \forall t \in {T ∖ T}_{1} , \;m \in M \tag{6} $$

$$ {I}_{m}^{t} = {I}_{m , 0}^{{s}_{d} ( t ) } - { \sum }_{\substack{{t}^{ ' } \in T : {s}_{\text{d}} ( {t}^{ ' } ) = {s}_{\text{d}} ( t ) , \\ {\tau}_{\text{d}} ( {t}^{ ' } ) \le {\tau}_{\text{d}} ( t ) }}{c}_{m}^{{t}^{ ' }} + { \sum }_{\substack{{t}^{ ' } \in T : {s}_{\text{a}} ( {t}^{ ' } ) = {s}_{\text{d}} ( t ) , \\ {\tau}_{\text{a}} ( {t}^{ ' } ) \le {\tau}_{\text{d}} ( t ) - \rho ( {s}_{\text{d}} ( t ) ) }}{u}_{m}^{{t}^{ ' }}\; \forall t \in T , \;m \in M \tag{7} $$

$$ {I}_{m , \text{end}}^{s} = {I}_{m , 0}^{s} - { \sum }_{t \in T : {s}_{\text{d}} ( t ) = s}{c}_{m}^{t} + { \sum }_{t \in T : {s}_{\text{a}} ( t ) = s}{u}_{m}^{t}\; \forall s \in S , \;m \in M \tag{8} $$

$$ {p}_{\text{diff}}^{t} \ge { \sum }_{c \in C : c \neq {p}_{0}^{t}}{x}_{c}^{t}\; \forall t \in T \tag{9} $$

$$ n{c}_{t} \ge { \sum }_{m \in M}{c}_{m}^{t} - o{c}_{t} \forall t \in T \tag{10} $$

$$ n{u}_{t} \ge { \sum }_{m \in M}{u}_{m}^{t} - o{u}_{t} \forall t \in T \tag{11} $$

$$ {I}_{m , \text{off}}^{s} \ge {I}_{m , \text{end}}^{s} - {i}_{m , \text{end}}^{s} \forall s \in S , \;m \in M \tag{12} $$

$$ {I}_{m , \text{off}}^{s} \ge {i}_{m , \text{end}}^{s} - {I}_{m , \text{end}}^{s} \forall s \in S , \;m \in M \tag{13} $$

$$ {I}_{m , 0}^{s} = {i}_{m , 0}^{s} \forall s \in S , \;m \in M \tag{14} $$

$$ {x}_{{p}_{0}^{t}}^{t} = 1 \forall t \in T : {\tau}_{\text{d}} ( t ) \le {\tau}_{\text{disr}} \tag{15} $$

$$ {c}_{m}^{t} , {u}_{m}^{t} , {I}_{m}^{t} \in {R}^{ + }\; \forall t \in T , \;m \in M \tag{16} $$

$$ {I}_{m , 0}^{s} , {I}_{m , \text{end}}^{s} , {I}_{m , \text{off}}^{s} \in {R}^{ + }\; \forall s \in S , \;m \in M \tag{17} $$

$$ n{c}_{t} , n{u}_{t} \in {R}^{ + } \forall t \in T \tag{18} $$

$$ {x}_{c}^{t} \in \{ 0 , 1 \} \; \forall t \in T , \;c \in {C}_{t} \tag{19} $$

$$ {z}_{c , {c}^{ ' }}^{t} \in \{ 0 , 1 \} \; \forall t \in T , \; ( c , {c}^{ ' } ) \in {\Gamma}_{t} \tag{20} $$

 
 

$$ {p}_{\text{diff}}^{t} \in \{ 0 , 1 \} \; \forall t \in T \tag{21} $$

The objective function (1) aims to minimize the number of driven carriage kilometers, the number of seat-shortage hours, the number of cancellations, off-balances in the ending inventories, the number of additional (un)coupled units and the number of different compositions compared to the initial rolling stock schedule. Constraints (2) ensure that exactly one rolling stock composition is chosen for each trip $t$. Constraints (3) link the binary variables by guaranteeing that a composition $c$ is chosen for trip $t$ if and only if an allowed composition change is chosen such that composition ${c}^{ ' }$ is used for the successor trip $v ( t )$ of trip $t$. Constraints (4) take on a similar role for the predecessor trips. Constraints (5) and (6) model the number of coupled and uncoupled rolling stock units for each composition change, respectively. Constraints (7) describe the inventory of rolling stock units after each trip. This is done by taking the initial inventory at the departure station of trip $t$, subtracting the number of rolling stock units that have been coupled to departing trains and adding the number of rolling stock units that have been uncoupled from arriving trains up until the departure of trip $t$. Constraints (8) model the ending inventories of each rolling stock unit type at each station, by adding all coupled units to and subtracting all uncoupled units from the initial inventory of the considered station. Constraints (9) ensure that the binary variable ${p}_{\text{diff}}^{t}$ takes on the value 1 if a different composition is chosen for trip $t$. Constraints (10) and (11) model the additional coupled and uncoupled units, respectively. Since the variables $n{c}_{t}$ and $n{u}_{t}$ are non-negative, only additional shunting movements are taken into account. Constraints (12) and (13) ensure that the variables ${I}_{m , \text{off}}^{s}$ are equal to the absolute value of the off-balance between the ending inventory of the original plan and the ending inventory of the adjusted plan. Constraints (14) specify that the initial inventories are equal to the planned initial inventories. Constraints (15) fix the chosen compositions for all trips that take place before the disruption occurs. Constraints (16)–(21) specify the domains of the decision variables.
